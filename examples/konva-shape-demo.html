Konva.js Shape Drawing Integration for PDF.js

Interactive demonstration of geometric shape drawing capabilities using Konva.js

🎯 Overview

This demonstrates the integration of Konva.js with PDF.js to enable drawing geometric shapes on the annotations layer. The implementation provides a canvas-based drawing system that complements the existing SVG-based annotation tools.

🚀 Key Features

Multiple Shape Types

Support for rectangles, circles, ellipses, lines, and arrows with real-time preview during drawing.

Interactive Manipulation

Built-in support for drag, resize, rotate operations using Konva's transformer.

Styling Options

Customizable stroke color, thickness, fill color, and transparency settings.

Export Capabilities

Export drawings as images (PNG/JPEG) or serialize for persistence.

📋 Implementation Details

Architecture Components

📁 src/display/ ├── konva_draw_layer.js # Main Konva canvas layer ├── editor/ │ ├── konva_shape_editor.js # Shape editor implementation │ └── drawers/ │ └── konva_shape_drawer.js # Shape drawing logic └── web/ └── konva_draw_layer_builder.js # Integration builder

Key Classes

KonvaDrawLayer

Manages the Konva Stage and Layer, handles shape creation, selection, and manipulation.

KonvaShapeDrawer

Extends Outline class, provides shape-specific drawing logic and configuration.

KonvaShapeEditor

Extends DrawingEditor, integrates with PDF.js annotation system and handles UI events.

KonvaDrawLayerBuilder

Builder pattern implementation for seamless integration with existing PDF.js page rendering.

Usage Example

// Create Konva draw layer const konvaLayer = new KonvaDrawLayer({ pageIndex: 0 }); konvaLayer.setParent(parentElement); // Draw a rectangle const rectId = konvaLayer.drawShape({ x: 10, y: 10, width: 100, height: 50, stroke: '#000000', strokeWidth: 2, fill: 'transparent' }, 'rect'); // Select and manipulate konvaLayer.selectShape(rectId);

🔧 Integration Benefits

Performance

Canvas-based rendering provides better performance for complex shape interactions compared to SVG DOM manipulation.

Rich Interactions

Built-in transformer with resize handles, rotation anchors, and smooth drag operations.

Extensibility

Modular design allows easy addition of new shape types and custom drawing tools.

Compatibility

Integrates seamlessly with existing PDF.js annotation system while maintaining architectural patterns.
